# CAÇA AOS BUGS

## Recuperação — Processo Fundamental de Testes

### Sobre a atividade

Este projeto faz parte de uma atividade de recuperação sobre qualidade e testes de software.

O sistema **Cantina Fácil** simula uma aplicação para gerenciamento de uma cantina escolar, permitindo realizar pedidos e consultar informações do sistema.

O objetivo da atividade é executar testes, identificar problemas e registrar os resultados encontrados.
